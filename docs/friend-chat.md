# 友人対局チャット

友人対局に参加済みの2人だけが任意で使う。部屋ごとの利用条件に同意するまで接続・受信しない。同意はメモリのみで、再読み込みや部屋の移動でリセットする。AI戦には表示しない。

本文はWebSocketで中継するだけで、D1、Durable Object storage、棋譜、localStorage、ログへ書き込まない。履歴・オフライン再送なし。受信から3秒でDOMから除去し、非表示タブでは本文を捨てる。相手側のコピー・撮影は防げない。

120文字・2秒間隔の制限に加え、サーバー側で短時間連投を切断。公開環境は既存のROOM_ACTION_BURSTも利用する。本文はtextContentで表示し、HTMLとして解釈しない。接続時に部屋の参加者認証・Origin・利用条件の版を検証し、送信時にも閉鎖と期限を確認する。トークンはURLに入れない。

CloudflareのROOM_CHAT Durable Object（WebSocket hibernation）を使用。接続と送信時にD1読み取りが発生するが、チャットの定期ポーリングとD1書き込みはない。接続メタデータには席・部屋ID・期限・送信制限時刻のみを持たせる。

公開時はwrangler.jsoncのroom-chat-v1 migrationとROOM_CHAT bindingを含むバックエンドWorkerを先にデプロイし、その後Pagesを更新する。Pages gatewayはWebSocketレスポンスをそのまま転送する。未設定のバックエンドではチャットのみ利用不可となり、対局は継続できる。

ローカルはnpm ci、npm startで動作。wsはローカルサーバー・テストのみで使い、ブラウザや公開Workerには含めない。

今回の実装・試験はローカルのみ。公開環境の接続試験と届出後の補正対応は別途確認する。

表示はスクロール位置に関係なく画面全体の右から左へ3秒で流れる方式。5段を順番に使用し、文字は駒のクリックを妨げない。動きを減らす端末設定では静止表示後3秒で消す。
